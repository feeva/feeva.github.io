맥 미니 M4에서 M6로 갈아탈 가치가 있을지 고민했다

이동련 · 2026. 8. 30.
IT 생활
목차

난 24년 12월에 맥 미니 M4를 사고부터 거의 2년 동안 맥 미니를 주력 컴퓨터로 사용하고 있다. 2년 동안 프리랜스 활동도 꽤 했고 재택 근무, 사이드 프로젝트, 취미 활동 등에 맥 미니를 사용한다. 아직도 윈도의 익숙한 UI가 더 낫다고 생각할 때가 있지만 쾌적한 성능은 다시는 윈도로 돌아갈 일이 없게 만들었다.

그런데 최근 새 맥 미니 모델로 M6와 M5 Pro가 발표되면서 업그레이드가 필요할까 알아보기로 했다. CPU, GPU, AI 성능이 많이 좋아졌다는데 AI 개발도 하고 가끔 무거운 작업을 돌리는 나한테 얼마나 이득이 있을까?

결론부터 말하자면 아직은 아니라는 것이다. 지금 새로 맥 미니를 산다면 M6의 장점이 충분하지만 이미 M4를 사용 중인 입장에서 M6는 아주 매력적으로 보이지는 않는다. M5 Pro는 299만원부터라 고민도 안 했다.

M4 성능은 아직도 차고 넘친다

내가 맥 미니 M4를 사용하면서 가장 좋았던 것은 Java 프로젝트의 maven 또는 gradle 빌드 속도였다. 이미 다른 사람의 M1 노트북에서 빌드 속도를 보면서 빠르다는 걸 알고 있었지만 M4는 한 차원 더 높아진 수준이었다.

당시 i9 CPU, 32GB 메모리의 윈도 노트북을 사용하고 있었는데 한 프로젝트를 빌드하는 데 약 12초가 걸렸다. 같은 노트북에 리눅스를 깔고 똑같은 소스를 빌드해보니 7~8초 정도로 줄었는데 16GB 메모리의 맥 미니 M4에서는 3~4초 정도밖에 걸리지 않았다.

CPU 하나만의 차이는 아니고 운영체계, JVM 등 여러 가지가 복합적이겠지만 맥 미니 M4의 성능은 엄청난 만족을 줬다. 개발하다 보면 코드 수정, 빌드, 배포를 하루에도 수십 번 반복하는데 빌드가 몇 초 만에 끝난다는 것은 거부할 수 없는 매력이었다.

이후에도 VS Code, Xcode 등의 도구와 Java, Python, JavaScript 등을 개발했는데 16GB 메모리임에도 Spring Boot 프로젝트나 Docker 컨테이너, 모바일 시뮬레이터 등을 띄워 사용하는 데 성능 때문에 답답했던 적은 없었다.

그런데 2년 가까이 지난 지금은 성능 체감 지점이 좀 달라졌다.

전에는 코드 수정, 빌드, 재실행을 반복했기 때문에 빌드 시간이 몇 초 줄어드는 것도 꽤 중요했다. 요즘은 AI 에이전트 기반으로 코딩하면서 그런 반복적인 작업이 많이 줄었다.

그래서 12초가 3초로 줄어든 차이가 하루 종일 누적되는 데 따른 효과보다는 다른 작업에서 효과를 본다. 현재 프로젝트에서는 한 번 실행하면 20분 정도 GPU를 사용해 결과를 내는 딥러닝 개발을 하고 있다. 이미지 7~8천 장 이상을 기반으로 모델을 학습시키는 것인데 20분이면 역시 상당히 빠른 것이다. 같은 작업을 GPU가 없는 운영 환경의 쿠버네티스 CPU 노드에서 실행하면 8~9시간 정도가 걸리기 때문에 모델을 로컬에서 개발하고 운영 환경으로 옮기는 방식을 취하고 있다.

그렇다면 M6는 얼마나 좋아졌을까?

이번 새 맥 미니는 CPU 성능도 좋아졌지만 GPU와 AI 연산 성능이 대폭 좋아졌다니 관심이 간다. Java 프로젝트 빌드가 3~4초에서 2초로 줄어든다고 해도 별로 관심이 가지 않지만 20분 걸리는 이미지 학습 작업이 10분 이하로 줄어든다면 살 만하지 않을까?

이미지 학습 같은 건 하루에 몇 번만 돌려도 수십분 차이가 날 수 있기 때문에 꽤 큰 차이로 볼 수 있다.

하지만 실제 사양을 들여다보면 20분이 10분으로 줄어들 것이라고 쉽게 기대하기는 어렵다. 딥러닝에서는 GPU 성능뿐 아니라 메모리 대역폭도 중요하다. 대량의 데이터를 GPU가 얼마나 빨리 읽고 쓸 수 있느냐가 영향을 주기 때문이다.

M4의 메모리 대역폭은 120GB/s이고 M6는 16GB 모델 기준 153GB/s, 24GB 이상 구성이면 170GB/s까지 올라간다. 분명 M4보다는 좋아졌다.

그런데 2년 전 나온 M4 Pro의 메모리 대역폭은 무려 273GB/s나 된다.

CPU GPU 코어 수 메모리 대역폭
M4 10 120GB/s
M6 16GB 12 153GB/s
M6 24/32GB 12 170GB/s
M4 Pro 최대 20 273GB/s
M5 Pro 최대 20 307GB/s

애플 발표로는 M6에 GPU 코어마다 AI 연산을 위한 Neural Accelerator가 추가됐고 M4 대비 AI 성능이 최대 4배, 그래픽 성능은 최대 2배라고 한다. 그럼 딥러닝 학습 시간이 반 이하로 줄어들까? 유튜브에 올라온 M4, M4 Pro의 GPU 작업 비교에 의하면 M4 Pro의 작업 시간이 대략 반 가까이 줄어드는 걸 볼 때 M6가 M4 Pro에 얼마나 필적할까에 달려있다고 본다.

아직 M6는 사전 주문 시점이라 실사용 경험이 안 나왔으니 이 부분은 조금 더 지켜볼 필요가 있다.

가격은 어떨까?

성능만큼 중요한 것이 가격이다.

내가 산 M4 모델은 메모리 16GB, SSD 512GB 구성이고 2024년 말 119만원이었다. 그런데 현재 중고 시장을 보면 같은 구성이 대략 120만~130만원 정도에 올라와 있고 단순 개봉 제품은 140만원대에 올라오기도 한다.

2년 가까이 사용한 컴퓨터가 중고 가격이 더 높게 된 신기한 상황이다. 메모리 가격 상승에 따른 애플의 가격 인상이 있었고 M4 단종에 따른 품귀 등 부수적인 효과인 것 같다. 지금이 갈아타기는 좋은 시점일 것 같기는 한데 M6의 가격이 얼마일까?

같은 16GB 메모리, 512GB SSD로 구성하면 183만 9천원이다. 내 M4를 120만원 정도에 판다면 60여 만원을 더 내고 M6로 바꿀 수 있다.

60만원을 투자해서 바꾸는 게 좋은 선택일까?

내 결론은 M4 유지다

딥러닝 성능 향상은 아직 확인해야 하겠지만 내 결론은 60만원의 가치로는 투자하지 않겠다는 것이다. 이유는 이렇다.

  • 윈도에서 맥 미니로 바꿨을 때 Java 빌드 성능 향상으로 얻는 10초는 의미가 있었다. 10초 동안 다른 일은 못하기 때문에 막연히 기다리기만 해야 했고 그게 하루 종일 누적되면 차이가 크다. M4에서 M6로 바꾸는 것은 그 정도 체감은 안 될 것 같다.
  • 딥러닝은 시간이 꽤 길기 때문에 기다리는 동안 다른 일을 할 수 있다. 개발자는 한 시간에 최소 5분은 스트레칭도 해야 하지 않나?
  • 프로젝트에 따라 다양한 작업이 있음을 감안할 때 여전히 M4로 느리거나 답답함을 느낄 일이 별로 없다.
  • 60만원이면 중고 태블릿 가격이다. 그 돈을 다른 곳에 투자하는 게 낫겠다.

M4가 처음 출시됐을 때 엄청난 가성비를 보고 샀던 나로서 M6는 그런 임팩트가 확 체감되지 않는다. 지금 시점에 새로 산다면 M4에 비해 M6의 가격 인상이 상대적으로 작지만(M4로 같은 구성이 6월부터 134만 9천원이었다) 내 경우 중고를 처분하고 60만원을 투자하기는 쉽지 않다.

지금은 M4를 더 쓰기로 했다. M6가 별로라서가 아니다. 돈도 돈이고 M4가 아직 너무 충분하기 때문이다.
